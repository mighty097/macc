# SnowfallMac

Чистый исходный проект приложения снегопада для macOS. В архиве нет старых патчей, корневых копий Swift-файлов и дублирующихся GitHub Actions workflow.

## Возможности

- Прозрачный click-through слой снега поверх окон и отдельный слой за окнами.
- GPU-отрисовка снежинок через MetalKit с instanced rendering.
- Мягкие снежные спрайты, глубина, вращение и вихревое поле ветра.
- Двухслойные сугробы: рыхлый верх и уплотнённая основа; оба слоя участвуют в осыпании, но с разной подвижностью.
- Лавинное перераспределение выполняется симметрично за кадр: склон выравнивается без систематического смещения в одну сторону.
- Падение снежинок создаёт локальные округлые наносы; переполненные участки передают избыток соседним свободным ячейкам.
- Края сугробов постепенно сбрасывают снег отдельными комками, если для них есть свободные слоты частиц.
- Снег на верхних границах видимых окон и на нижнем горизонтальном Dock.
- Геометрия Dock читается через macOS Accessibility API; требуется отдельное разрешение для SnowfallMac.app.
- Смахивание снега курсором по непрерывной траектории без повторной обработки одних и тех же ячеек; даже небольшие снятые порции формируют видимый порошок.
- При перемещении окна снег отделяется пространственными группами и получает инерцию, противоположную движению окна по обеим осям.
- Если лимит частиц достигнут, не выпущенная часть при обычном смахивании и осыпании остаётся на поверхности, а не удаляется бесследно.
- Сброшенный снег остаётся в полёте до столкновения с нижним окном или нижней границей экрана; частицы не исчезают по короткому таймеру.
- Осыпание краёв Dock направлено наружу, чтобы снег обходил закруглённые края панели.
- Сохранение сугроба при кратковременном исчезновении окна из системного списка.
- Три уровня интенсивности, режим «Только Finder», очистка сугробов.
- Снижение частоты и количества частиц на батарее; пауза при сне дисплеев и полноэкранном окне.

Проект предназначен именно для снегопада. Другие погодные эффекты и игровые объекты не входят в состав.

## Изменения в этой версии

- Переработано осыпание при перемещении окон: вместо попытки создать частицу для каждой ячейки снег выпускается компактными группами, а сила и направление выброса учитывают движение окна.
- Смахивание мышью больше не удаляет микропорции без эффекта порошка; если для частиц нет места, снятый снег возвращается в сугроб.
- Переполнение при оседании перераспределяется в соседние ячейки.
- Рыхлый снег перемещается по склонам быстрее уплотнённого; плотный слой тоже может сдвигаться при достаточно крутом склоне.
- Буферы лавинного расчёта переиспользуются, чтобы не создавать два временных массива на каждом кадре для каждого окна.

Полная сборка приложения требует проверки через GitHub Actions: синтаксический разбор Swift-файлов сам по себе не подтверждает успешную macOS-сборку.

## Сборка без Xcode на локальном Mac

1. Загрузите всё содержимое этого архива в корень нового GitHub-репозитория. Скрытую папку `.github` тоже нужно загрузить.
2. Назовите основную ветку `main`.
3. Откройте вкладку **Actions** и выберите **Build SnowfallMac**.
4. После успешной сборки скачайте артефакт **SnowfallMac-universal**.

GitHub Actions собирает приложение для Apple Silicon (`arm64`) и Intel (`x86_64`), отдельно компилирует встроенный Metal shader и упаковывает приложение в ZIP. Локально устанавливать Xcode не требуется.

## Разрешение для Dock

Для накопления снега на Dock приложению нужен доступ Accessibility. После первой сборки и запуска добавьте **SnowfallMac.app** в:

**System Settings → Privacy & Security → Accessibility**

Разрешение Terminal, которым запускаются диагностические скрипты, не передаётся самому приложению. Без разрешения Dock-поверхность не определяется; снег на обычных окнах и у нижней границы экрана продолжает работать.

Текущая реализация Dock рассчитана на горизонтальный Dock внизу экрана. Скрытый Dock, боковое расположение и несколько дисплеев требуют отдельной проверки на конкретной конфигурации.

## Структура

- `SnowfallMac/Sources` — исходный Swift-код приложения.
- `SnowfallMac/Info.plist` — параметры приложения.
- `SnowfallMac.xcodeproj` — проект и общая схема Xcode.
- `.github/workflows/build-macos.yml` — единственный workflow сборки.

## Требования

- macOS 13 или новее.
- Для автоматической сборки — GitHub Actions с macOS runner.
- Для локальной сборки вручную — Xcode 15 или новее.

## Ограничения сборки

CI создаёт ad-hoc подписанный ZIP, а не Developer ID и не notarized приложение. macOS может показать предупреждение Gatekeeper при первом открытии. Для распространения вне личного использования понадобится Developer ID и notarization.
